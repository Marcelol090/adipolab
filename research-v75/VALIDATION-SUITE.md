# Validação de dados publicados v162

Execute `node research-v75/run-validation-suite.mjs` para gerar um relatório JSON no terminal; `node --test research-v75/validation-suite.test.mjs` para testar o motor. A interface `validation-suite.html` executa os mesmos controles. Três fontes foram reconferidas em 26/11/2026: seções do artigo biológico, excerto do artigo metabolômico e resumo do artigo sobre equações. As cinco verificações reconciliam dados agregados e conclusões publicadas, não reproduzem o experimento original. Não são testes de eficácia, toxicidade ou intervenções, não há dados brutos importados nem resultados fisiológicos pessoais. GIVIMP é referência metodológica, não certificação. A realização física, clínica ou de pesquisa com amostras exige profissionais, autorização e avaliação ética aplicável. Nenhum dado pessoal é publicado.
